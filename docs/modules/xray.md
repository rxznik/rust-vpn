# rvpn-xray

Сборка конфига Xray и запуск бинарника v26.3.27. Версия записана в `resources/xray/VERSION`. Границы — в [docs/architecture.md](../architecture.md).

## Ответственность

Крейт `crates/xray` пишет JSON одного процесса и следит за его жизнью. Входящие сокеты остаются на `127.0.0.1`. Подписка из готового JSON проходит `prepare_passthrough` и не переписывает исходящие.

## Файлы

- `src/lib.rs` — реэкспорт
- `src/compile.rs` — `compile` и `prepare_passthrough`
- `src/process.rs` — `Supervisor`, поиск бинарника, снимок статистики
- `src/stream.rs` и файлы протоколов (`vless`, `vmess`, `trojan`, `shadowsocks`, `socks`, `hysteria`, `wireguard`, `json_outbound`) — исходящий узел

## Основные типы

`CompileRequest` — сервер, `CoreSettings`, необязательные fragment и noise, документы маршрута и DNS. `Supervisor` запускает и останавливает процесс. `SpawnSpec` — путь к бинарнику, аргументы, текст конфига и каталог. `StatsPoller` отдаёт `TrafficStats` снимком. `ProcessError` — ошибка записи конфига или ранний выход процесса.

## Главный сценарий

Сессия коммитит маршрут, вызывает `compile` для обычного сервера или `prepare_passthrough` для JSON-подписки и передаёт текст в `Supervisor::start`. Пока окно не просит статистику, фоновый опрос спит и не запускает процесс.

## Как устроено

SOCKS и HTTP слушают `127.0.0.1`. Sniffing включает `routeOnly`: имя для маршрута снимается, исходный ClientHello не подменяется. Если заданы fragment или noise, компилятор добавляет исходящий freedom с тегом `fragment` и ставит `dialerProxy` у прокси.

У JSON-подписки listen допускается только на loopback. Пустой `api.listen` становится `127.0.0.1:10085`. Пути журналов остаются внутри каталога сессии. Поля `tls.insecure` и флаг Hysteria2 `insecure` из ссылки читаются и в JSON не пишутся: проверка сертификата остаётся включённой, `allowInsecure` не появляется.

Статистика читается командой `api statsquery` по счётчикам `outbound>>>proxy>>>traffic`. Опрос раз в 10 секунд. `locate_binary` смотрит переменную `XRAY_BIN`, затем `xray` рядом с программой, затем `resources/xray` только этой платформы. `Supervisor::start` ждёт 250 мс и один раз повторяет запуск, если процесс вышел сразу. Конфиг пишется в `xray.json` с правами `0600` на Unix. В памяти журнала — 200 строк.

## Сильные стороны

Входящие не уходят с машины. Флаг «не проверять сертификат» из ссылки конфиг не выключает. Пока статистика не нужна, лишний процесс `xray api` не стартует.

## Слабые стороны

Установленная копия находит Xray рядом с `rustvpn`. Каталог `resources/xray` остаётся для `cargo run` и берётся только для текущей платформы. Пауза 250 мс остаётся. Снимок трафика всё ещё получается отдельным запуском `xray api`, а не из уже живущего процесса.
